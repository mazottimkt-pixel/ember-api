# Conversational Transcript Testing

A unidade de aceitação é a conversa completa, não somente o parser.

Cada transcript define estado inicial, mensagens, memória, `TaskStateV1` esperado por turno, patches aceitos/rejeitados, tools esperadas, outbound e estado final.

Cobertura inicial:

- orçamento composto e fracionado;
- correção e pagamento;
- pedido de compra;
- legado contaminado;
- menu durante tarefa;
- confirmação por texto.

Próximos transcripts obrigatórios: CNPJ cadastrado/dispensado, Cofre e consulta durante tarefa, botão expirado, fallback Meta, reinício do Node, WAMID duplicado e branding pós-documento.
